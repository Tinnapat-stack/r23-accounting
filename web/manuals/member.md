# คู่มือสมาชิก — ระบบบัญชี รุ่นที่ 23

ระบบนี้ใช้เก็บและบันทึกเงินกองกลางของรุ่น ทุกคนดูได้ว่ารุ่นมีเงินเท่าไร และเงินถูกใช้ไปกับอะไร พร้อมใบเสร็จ

## 1. สมัครและเข้าสู่ระบบ

1. ขอให้แอดมินเพิ่มชื่อคุณในระบบก่อน (รหัสนิสิต + อีเมล)
2. เปิดเว็บ กด **สมัครใช้งาน** แล้วกรอก **รหัสนิสิตและอีเมลเดียวกับที่แจ้งแอดมิน** ตั้งรหัสผ่านอย่างน้อย 8 ตัว
3. เปิดอีเมล กดลิงก์ยืนยัน แล้วกลับมา **เข้าสู่ระบบ**

ถ้าขึ้นว่า "ไม่พบรหัสนิสิตและอีเมลนี้ในรายชื่อ" แปลว่ายังไม่ได้ถูกเพิ่ม หรือพิมพ์อีเมลไม่ตรงกับที่แจ้งแอดมิน
ลืมรหัสผ่าน กด **ลืมรหัสผ่าน** ในหน้าเข้าสู่ระบบ ระบบจะส่งลิงก์ไปที่อีเมล

## 2. ดูยอดที่ต้องจ่าย

หน้า **หน้าหลัก** บอกยอดค้างของคุณแยกตามรายการ และเงินกองกลางของรุ่นคงเหลือ
ถ้ายังค้าง ระบบจะเตือนที่ 🔔 ก่อนครบกำหนด 3 วัน และสัปดาห์ละครั้งหลังเลยกำหนด

## 3. แจ้งชำระ (ส่งสลิป)

1. โอนเงินเข้าบัญชีที่แสดงในหน้า **แจ้งชำระ**
2. กรอกยอดที่โอน วันเวลาที่โอน และแนบรูปสลิป (JPG, PNG หรือ WEBP ไม่เกิน 5 MB)
3. ติ๊กรายการที่ต้องการจ่าย และใส่ยอดของแต่ละรายการ
4. กด **ส่งข้อมูล** สถานะจะเป็น **รอตรวจสอบ** เหรัญญิกจะตรวจกับบัญชีธนาคาร แล้วกดยืนยัน

- **จ่ายบางส่วน:** ใส่ยอดน้อยกว่ายอดค้างได้ ส่วนที่เหลือยังค้างอยู่
- **จ่ายเกิน:** ส่วนที่เกินเป็น **เครดิต** กด **ใช้เครดิตตัดยอด** ที่หน้าหลักเพื่อจ่ายรายการถัดไป
- **จ่ายแทนเพื่อน:** กด **+ จ่ายแทนเพื่อน** ใส่รหัสนิสิตเพื่อน เลือกรายการ และยอด

ยอดของคุณจะลดลง **หลังเหรัญญิกยืนยันแล้วเท่านั้น** ระบบจะแจ้งผลที่ 🔔

## 4. ถ้าสลิปไม่ผ่าน

ดูเหตุผลที่หน้า **การชำระของฉัน** แก้ตามนั้นแล้วส่งใหม่ สลิปเดิมยังเก็บไว้เป็นประวัติ
ส่งผิดและยังไม่ถูกตรวจ กด **ยกเลิก** ได้

ถ้าเหรัญญิกตรวจพบภายหลังว่าเงินไม่เข้าจริง สลิปจะขึ้นว่า **ยกเลิกหลังยืนยัน** พร้อมเหตุผล และยอดจะกลับมาค้างเหมือนเดิม
ถ้าได้รับเงินคืน (โอนเกิน หรือกิจกรรมยกเลิก) จะเห็นในหน้า **การชำระของฉัน** หัวข้อ "เงินที่ได้รับคืน"

## 5. ขอเบิกเงิน (เมื่อต้องจ่ายค่าใช้จ่ายของรุ่น)

1. เมนู **เบิกจ่าย** → **+ ขอเบิกเงิน**
2. กรอกว่าซื้ออะไร จำนวนเงิน หมวด กิจกรรม เหตุผล และแนบใบเสนอราคา (ถ้ามี)
3. รอเหรัญญิกอนุมัติ → เหรัญญิกจ่ายเงินและแนบใบเสร็จ → ระบบแจ้งคุณที่ 🔔

ยกเลิกได้เองเฉพาะตอนที่ยังรออนุมัติ

## 6. ดูว่าเงินของรุ่นไปไหน

- **สรุปการเงิน:** เงินคงเหลือ รายรับ รายจ่าย กราฟรายเดือน และรายจ่ายทุกรายการพร้อมใบเสร็จ
- **งบประมาณ:** งบแต่ละกิจกรรม ใช้ไปเท่าไร เหลือเท่าไร
- **รายงาน:** ดาวน์โหลดรายจ่ายเป็นไฟล์เปิดใน Excel หรือพิมพ์เป็น PDF

## 7. ใครเห็นข้อมูลของคุณ

| ข้อมูล | ใครเห็น |
| --- | --- |
| ยอดค้าง สลิป และประวัติการชำระของคุณ | คุณ, เหรัญญิก, ผู้ตรวจสอบ (ประธานและแอดมินเห็นยอดค้าง แต่ไม่เห็นสลิป) |
| ว่าคุณจ่ายครบแล้วหรือยัง | สมาชิกคนอื่นเห็นแค่จำนวนรวม เช่น "จ่ายครบ 24/30 คน" ไม่เห็นชื่อ |
| คำขอเบิกและใบเสร็จ | สมาชิกทุกคน (เพื่อความโปร่งใส) |

## 8. ติดปัญหา

- เข้าสู่ระบบไม่ได้ ชื่อหรืออีเมลผิด → **แอดมิน**
- ยอดไม่ตรง สลิปค้างนาน → **เหรัญญิก** (บอกวันเวลาที่โอนและยอด)
