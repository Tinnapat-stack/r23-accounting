# คู่มือผู้ดูแล — เหรัญญิก ประธาน ผู้ตรวจสอบ แอดมิน

อ่าน [คู่มือสมาชิก](member.md) ก่อน ทุกคนเป็นสมาชิกด้วย และหนึ่งคนมีได้หลายตำแหน่ง

## หลักที่ทุกตำแหน่งต้องรู้

- **ลบรายการเงินไม่ได้ รวมถึงแอดมิน** ถ้าผิดต้องยกเลิกพร้อมเหตุผลแล้วทำใหม่
- **ทุกการกระทำถูกบันทึก** ว่าใครทำ เมื่อไร และเหตุผลอะไร (ผู้ตรวจสอบและแอดมินดูได้ที่ **ประวัติการกระทำ**)
- **แอดมินดูแลระบบ ไม่ได้ดูแลเงิน** แอดมินไม่เห็นสลิปและสมุดบัญชี ถ้าไม่มีตำแหน่งเหรัญญิกด้วย


## เหรัญญิก

### ตรวจสลิป (เมนู ตรวจสลิป)

1. เปิดสลิปที่รอตรวจ ดูรูปคู่กับข้อมูลที่สมาชิกกรอก
2. **เปิดแอปธนาคารดูว่าเงินเข้าจริง** ยอด เวลา และชื่อผู้โอนตรงกัน รูปสลิปปลอมได้ อย่ายืนยันจากรูปอย่างเดียว
3. ถ้าระบบขึ้นกล่องเหลือง **"พบไฟล์สลิปเดียวกัน"** หรือ **"เลขอ้างอิงเดียวกัน"** ให้เปิดดูรายการนั้นก่อน อาจเป็นสลิปที่ใช้ซ้ำ
4. ถูกต้อง → **ยืนยันรับเงิน** ไม่ถูกต้อง → เลือกเหตุผล → **ไม่ผ่าน** (สมาชิกจะเห็นเหตุผล)

เหรัญญิกหลายคนกดพร้อมกันได้ ระบบให้ผ่านแค่คนแรก คนที่สองจะเห็นว่า "ถูกตรวจไปแล้ว"

### เบิกจ่าย (เมนู เบิกจ่าย)

1. คำขอใหม่ → ตรวจเหตุผลและใบเสนอราคา → **อนุมัติ** หรือ **ไม่อนุมัติ** พร้อมเหตุผล
   ถ้าจะเกินงบกิจกรรม ระบบขึ้นคำเตือน ⚠ (ยังกดอนุมัติได้ ให้แน่ใจว่ารุ่นเห็นด้วย)
2. อนุมัติแล้ว **ยังไม่หักเงิน** หลังจ่ายเงินจริง → ใส่ยอดที่จ่ายจริง แนบใบเสร็จหรือสลิปโอน → **บันทึกการจ่าย**
3. ยกเลิกคำขอที่ยังไม่จ่ายได้พร้อมเหตุผล
4. **บันทึกจ่ายผิด** (ยอดผิด แนบใบเสร็จผิด) → เปิดคำขอ → **ยกเลิกการจ่าย (บันทึกผิด)** → ใส่เหตุผล
   คำขอกลับเป็น "อนุมัติแล้ว รอจ่าย" เงินกองกลางกลับมาเท่าเดิม แล้วบันทึกจ่ายใหม่ให้ถูก ทุกคนเห็นหมายเหตุว่าเคยยกเลิกเพราะอะไร

อนุมัติคำขอของตัวเองได้ (ตามที่รุ่นตกลง) แต่ระบบบันทึกไว้ชัดเจน ถ้ามีเหรัญญิกคนอื่น ควรให้อีกคนอนุมัติ

### ยอดยกมา (เมนู สรุปการเงิน)

ตั้งครั้งเดียวตอนเริ่มใช้ระบบ: ใส่เงินที่รุ่นมีอยู่ก่อนเริ่มระบบ และที่มา เช่น "ยอดสมุดบัญชี ณ 1 พ.ย. 2569 รับรองโดยประธาน"
ตั้งใหม่ได้ ของเดิมจะถูกยกเลิกแต่ยังเห็นในประวัติ

### เทียบยอดกับธนาคาร (ทำทุกสัปดาห์)

ระบบยังไม่มีหน้ากระทบยอดอัตโนมัติ ให้ทำด้วยมือ:

1. ดู **เงินคงเหลือ** ในหน้าสรุปการเงิน
2. เทียบกับยอดในแอปธนาคาร
3. ถ้าไม่ตรง ดาวน์โหลด **รายงานรายรับรายรายการ** และ **รายจ่าย** ของช่วงนั้น เทียบกับรายการเดินบัญชีทีละรายการ
4. ส่วนต่างที่มักเจอ: สลิปที่โอนแล้วแต่ยังไม่ได้กดยืนยัน, จ่ายเงินแล้วแต่ยังไม่บันทึกการจ่าย, ค่าธรรมเนียมธนาคาร

### เมื่อมีคนแจ้งว่ายอดผิด

1. ขอวันเวลาโอน ยอด และรูปสลิปจากผู้แจ้ง
2. ค้นในหน้าตรวจสลิป (เลือกสถานะ "ยืนยันแล้ว" หรือ "ไม่ผ่าน") และเทียบกับธนาคาร
3. ถ้ายังไม่ได้ยืนยัน → ตรวจและยืนยันตามปกติ
4. **ถ้ายืนยันผิดไปแล้ว** (เช่น ยืนยันสลิปที่เงินไม่เข้าจริง) เปิดสลิปนั้นในหน้าตรวจสลิป → **ยกเลิกรายรับนี้** → ใส่เหตุผล
   ยอดค้างของสมาชิกจะกลับมาเหมือนก่อนยืนยัน รายรับเดิมยังเห็นในประวัติพร้อมเหตุผล และสมาชิกได้รับแจ้ง
   ถ้าคืนเงินจากยอดของสลิปนั้นไปแล้ว ระบบจะไม่ให้ยกเลิก เพราะยอดจะติดลบ
5. แจ้งผลกับผู้แจ้ง

### คืนเงินสมาชิก

**โอนเงินคืนก่อนเสมอ** แล้วค่อยบันทึกในระบบพร้อมรูปสลิปโอนคืน (สมาชิกคนอื่นไม่เห็นสลิปนี้ เพราะมีชื่อผู้รับ)

- **คืนเงินที่โอนเกิน (เครดิต):** เมนู **คืนเงิน** → แถวของสมาชิก → **คืนเครดิต** คืนได้ไม่เกินเครดิตที่เหลือ
- **คืนค่ารายการที่จ่ายแล้ว** (เช่น กิจกรรมยกเลิก เรียกเก็บผิดคน): เมนู **รายการเรียกเก็บ** → เปิดรายการ → แถวของสมาชิก → **คืนเงิน**
  ยอดที่ต้องจ่ายของคนนั้นจะลดลงเท่ากับที่คืน จึงไม่กลายเป็นยอดค้าง
- ประวัติการคืนเงินทั้งหมดอยู่ที่เมนู **คืนเงิน** ผู้ตรวจสอบดูได้ สมาชิกเห็นเฉพาะเงินที่ตัวเองได้รับคืน
- หน้าสรุปการเงินแสดงยอดคืนเงินรวมแยกจากรายจ่าย ไม่บอกว่าคืนให้ใคร


## ประธาน

- **รายการเรียกเก็บ:** สร้างรายการใหม่ ใส่ชื่อ ยอดต่อคน วันครบกำหนด เก็บทุกคน หรือใส่รหัสนิสิตเฉพาะคน สมาชิกจะได้รับแจ้งทันที ปิดรับชำระได้เมื่อเก็บครบ
- **เตือนยอดค้าง:** ถ้าใส่วันครบกำหนด ระบบเตือนคนที่ยังค้างเองทุกเช้า 8 โมง (3 วันก่อนครบกำหนด 1 ครั้ง และสัปดาห์ละครั้งหลังเลยกำหนด) เปิดรายการแล้วกด **ส่งเตือนคนที่ยังค้าง** เพื่อเตือนเพิ่มได้ (เหรัญญิกกดได้ด้วย ส่งถึงคนเดิมได้วันละครั้ง) ปิดรับชำระแล้วระบบหยุดเตือน
  การเตือนเป็นแจ้งเตือน 🔔 ในเว็บ คนที่ไม่เปิดเว็บจะยังไม่เห็น
- **งบประมาณ:** เพิ่มกิจกรรมและตั้งงบ แก้งบได้ภายหลัง
- ดูยอดค้างรายคนได้ที่หน้ารายการเรียกเก็บ (สมาชิกทั่วไปไม่เห็นรายชื่อนี้)

## ผู้ตรวจสอบ

ดูได้ทุกอย่าง แต่แก้อะไรไม่ได้: สลิปทุกใบ สมุดบัญชี รายงานรายคน และ **ประวัติการกระทำ**
แนะนำให้สุ่มตรวจทุกเดือน: สลิปที่ยืนยันแล้วตรงกับธนาคารไหม, รายจ่ายมีใบเสร็จครบไหม, มีใครอนุมัติคำขอของตัวเองบ่อยไหม

## แอดมิน (เมนู สมาชิกและตั้งค่า)

- **เพิ่มสมาชิก:** ทีละคน หรือ **นำเข้า** โดยวาง 3 คอลัมน์ (รหัสนิสิต ชื่อ อีเมล) จาก Excel หรือ Google Sheets ดู "วิธีกรอก" ใต้ช่องนำเข้า
- **ให้ตำแหน่ง:** ติ๊กช่องในแถวของคนนั้น ให้ตำแหน่งตัวเองไม่ได้ ควรมีแอดมินอย่างน้อย 2 คน
- **ระงับบัญชี:** เช่น คนลาออก ต้องใส่เหตุผล สิทธิ์ทั้งหมดหยุดทันที ข้อมูลเดิมยังอยู่ เปิดใช้คืนได้
- **บัญชีรับเงิน:** เพิ่มบัญชีธนาคารหรือพร้อมเพย์ที่ให้สมาชิกโอนเข้า ปิดบัญชีเก่าได้
